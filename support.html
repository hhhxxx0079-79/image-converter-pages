日本語

基本的な使い方

  1. 画像をドラッグ＆ドロップするか、ファイル選択で追加します。
  2. 変換形式や必要な設定を選びます。
  3. 保存先フォルダを選択して変換を開始します。
  4. 変換結果を保存先で確認します。元画像は変更されません。

対応形式

JPEG/JPG、PNG、WebP、HEIC/HEIF、BMP、TIFFを扱います。出力形式はmacOSの対応状況によって異なる場合があります。

制限事項・よくある質問

  • 入力画像は1枚につき最大4,000万画素・512MiB、登録は最大1,000件です。大量ファイルの安定処理を保証するものではありません。48MP画像は画素数上限を超えます。
  • WebP出力は可逆圧縮です。最大寸法は縦横それぞれ16,383ピクセルです。アニメーションWebPや複数フレーム・複数ページの保持には対応しません。
  • JPEG・BMPへの変換では透明部分が白背景になります。
  • 16bit/HDRの完全保持やICC・EXIF情報の完全な引き継ぎは保証しません。撮影日時や位置情報などが残る場合があります。メタデータ削除機能はありません。
  • 保存先のファイルシステムがハードリンクに対応しない場合など、保存できないことがあります。
  • キャンセルはエンコード処理中にすぐ反映されない場合があります。すでに保存された出力は自動削除されません。
  • 「変換完了を通知」はアクセシビリティの読み上げ案内であり、通知センターのバナー表示ではありません。
  • 保存先へのアクセスに問題がある場合は、アプリ内で保存先を再選択してください。

問い合わせ時に教えてほしいこと

macOSのバージョン、画像形式、操作手順、表示されたエラー内容をお知らせください。画像ファイルそのものや個人情報を送る必要はありません。

English

Getting started

  1. Add images using drag and drop or the file picker.
  2. Choose the output format and settings.
  3. Select an output folder and start conversion.
  4. Check the converted files in the selected folder. Originals are not modified.

Supported formats

JPEG/JPG, PNG, WebP, HEIC/HEIF, BMP, and TIFF. Available output formats may depend on macOS support.

Limitations and FAQ

  • Each input image is limited to 40 million pixels and 512 MiB; up to 1,000 files may be added. This does not guarantee stable processing of 1,000 files. 48 MP images exceed the pixel limit.
  • WebP output uses lossless compression, with a maximum of 16,383 pixels per dimension. Animated WebP and preservation of multiple frames or pages are not supported.
  • Transparent areas become white when exporting to JPEG or BMP.
  • Full preservation of 16-bit/HDR data or ICC/EXIF metadata is not guaranteed. Dates and location metadata may remain in output images. There is no metadata-removal feature.
  • Saving may fail on file systems that do not support the required hard-link operation.
  • Cancellation may not take effect immediately during encoding. Files already written are not automatically deleted.
  • “Announce completion” is an accessibility spoken announcement, not a guaranteed Notification Center banner.
  • If access to the destination fails, select the output folder again in the app.

Contacting support

Please include your macOS version, image format, steps to reproduce, and any error message. You do not need to send your image files or personal information.
